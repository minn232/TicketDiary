
--------------- 서버 접속 후 실행할 명령어들 ---------------

- 1. 파일이 있는 폴더로 이동 후, 백그라운드에서 도커 컨테이너 실행
sudo docker-compose up -d

- 2. Qwen2.5-VL 모델이 메모리에 잘 올라가고 있는지 실시간 로그 확인 (빠져나올 땐 Ctrl+C)
sudo docker logs -f qwen-vl-server

- 3. 임베딩 모델이 잘 올라갔는지 확인
sudo docker logs -f bge-m3-server
